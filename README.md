# 💩💰

CrappyLoot is a project who's main goal is to examine and rank the increasingly hostile microtransactions that pervade modern video games

## Rankings

* Games are ranked only if they contain microtransactions
* Table is ranked from worst to worse in descending order. The more 💩 a game has, the worse it is.
